              /eoselya-program/photos/...
              /eoselya-program/fonts/...
              /eoselya-program/vendor/...
              /eoselya-program/favicon/...
              /eoselya-program/intro.mp4
4. Адреса сторінки лишається та сама:
   https://park-sovinon.ua/eoselya-program/

Це статичний сайт: HTML + CSS + JS + картинки. PHP, бази даних,
composer, npm і збірка НЕ потрібні. Нічого налаштовувати не треба.

ВАЖЛИВО
════════════════════════════════════════════════════════════════
• Усі шляхи всередині — відносні, тож тека може лежати де завгодно.
  АЛЕ якщо адреса зміниться (не /eoselya-program/), треба виправити
  три рядки на початку index.html (рядки 12-14):
      og:image, og:url, canonical
  Там прописано https://park-sovinon.ua/eoselya-program/

• Сервер має віддавати ці типи файлів (зазвичай уже налаштовано):
      .webp  →  image/webp
      .woff2 →  font/woff2
      .mp4   →  video/mp4
  Якщо .webp або .woff2 не налаштовані, не буде видно фото і шрифтів.

• Файл .nojekyll потрібен лише для GitHub Pages. На звичайному
  сервері він нічого не робить — можна лишити або видалити.

• Сторінка важить близько 41 МБ, з них 5 МБ — відеофайл intro.mp4
  на першому екрані. Він вантажиться ПІСЛЯ повного завантаження
  сторінки і на її швидкість не впливає.

ПЕРЕВІРКА ПІСЛЯ ЗАМІНИ
════════════════════════════════════════════════════════════════
1. Сторінка відкривається, на першому екрані видно фото, а через
   кілька секунд починає йти відео.
2. Видно фотографії в блоках «Про комплекс» і «За що обирають»
   (якщо замість фото порожні місця — не налаштований тип .webp).
3. Текст виглядає фірмовим шрифтом, а не системним
   (якщо системним — не налаштований тип .woff2).
4. Внизу сторінки завантажується карта.
5. Кнопка «Залишити заявку» праворуч унизу відкриває опитувальник.
6. Калькулятор рахує: перемикаються будинки, рухаються повзунки.
7. Унизу праворуч має з'явитися кнопка дзвінка від Binotel.

Питання щодо самої сторінки — до маркетингу.
